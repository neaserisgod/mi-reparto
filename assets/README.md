# Mapa

`mapa_estilo.json` adapta la paleta del estilo Positron de OpenFreeMap.
Origen: https://tiles.openfreemap.org/styles/positron
Proyecto: https://openfreemap.org/ (estilos basados en OpenMapTiles).
Los datos cartográficos pertenecen a OpenStreetMap y sus colaboradores (ODbL).
El control de atribución de MapLibre permanece visible en el mapa.
No se incluye ningún dato personal en este directorio.

Se conserva el texto de las licencias en `LICENCIAS_MAPA.txt`, incluido en el APK.
Positron deriva del diseño de Stamen y Paul Norman para CartoDB, con aportes de MapTiler y OpenMapTiles; OpenFreeMap adapta el estilo y Mi Reparto modifica la paleta. Código BSD-3-Clause/MIT y diseño CC BY 4.0 según los avisos originales.
